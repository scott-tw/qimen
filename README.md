# 九宮問事

奇門遁甲（時家奇門）排盤網頁工具（轉盤・拆補法）。輸入時間起盤，依問事類別標出用神，產生白話解讀，並可複製給親友的簡易說明。

整個工具是一個單一網頁檔（`index.html`），所有計算都在瀏覽器裡完成。不需要後台、資料庫或帳號登入，也不會上傳任何資料。

> 奇門遁甲屬傳統術數，沒有科學證據支持其預測力。本工具的解讀僅供參考，不能取代醫療、法律、財務等專業判斷。

## 功能

- **兩種盤**：占事盤（以提問當下的時間起盤，一次問一件事）、出生命盤（以出生時間起盤）。
- **完整盤面**：八神、九星（含月令旺相休囚廢）、八門、天盤干、地盤干、旬首、空亡、驛馬、值符、值使。
- **狀態標記**：門迫、宮迫、門入墓、擊刑、空亡、馬星，以及常見格局（青龍返首、飛鳥跌穴、大格、伏吟等）。
- **問事類別與用神**：

  | 類別 | 用神 |
  |---|---|
  | 事業・工作・聘任 | 本人、這件事、開門、值符、六合 |
  | 財運・投資・生意 | 本人、這件事、生門、戊 |
  | 健康・疾病 | 病人（本人／男性長輩／女性長輩／其他）、天芮、天心、生門、死門 |
  | 感情・婚姻 | 本人、對方（男問看乙、女問看庚）、六合 |
  | 出行・搬遷・洽談 | 本人、開門、休門、生門、馬星 |
  | 考試・學業 | 本人、天輔、景門、丁 |
  | 官司・談判・人際 | 本人、對方、開門、值符 |
  | 一般問事 | 本人、這件事、值符、值使 |
  | 出生命盤概覽 | 本人、值符、值使、開門、生門、天芮 |

- **白話解讀**：每個用神會標示「順／普通／較吃力」，附上一句建議，以及白話的有利與留意原因。最上方是整體結論。
- **時間參考**：列出空亡填實日、驛馬日的日期。
- **分享**：可複製完整解讀，或複製給親友的簡易版（會淡化凶神、凶門等用詞）。
- **紀錄**：盤可以存在使用者自己的瀏覽器（localStorage），每個人只看得到自己的紀錄。

## 排盤方法

- **局數**：時家奇門轉盤，以拆補法定局。
  - 陰陽遁與局數，以起盤當下所在的節氣決定。節氣時刻精確到分鐘，涵蓋 1902–2100 年。
  - 上中下元，以符頭（最近的甲、己日）的地支決定：子午卯酉為上元，寅申巳亥為中元，辰戌丑未為下元。
- **子時**：23:00–24:00 預設算作隔天，可在「進階」改為算作當天。
- **時間**：一律以台灣時間（UTC+8）輸入，不做真太陽時校正。
- **月令強弱**：依季節五行判斷。辰、戌、丑、未月在立春、立夏、立秋、立冬前 18 天為土旺。
- **寄宮**：中五宮寄坤二宮，天禽隨天芮。

### 正確性驗證

- 以開源排盤程式 [kinqimen](https://pypi.org/project/kinqimen/)（拆補法）隨機比對 220 組 1930–2040 年的時間，比對局數、八門、九星、八神、天盤與地盤。
- 結果：218 組完全一致。
- 不一致的 2 組，是時干落在中五宮的情況。kinqimen 在這種情況下九星留在原位，天盤干卻移動了，前後自相矛盾。本工具依轉盤規則，讓天盤干隨九星一起移動。
- 比對資料在 `src/test/reference-kinqimen.json`。

## 檔案結構

```
index.html                         ← 網站本體（由 src/build.js 產生，可直接部署）
src/
  engine.js                        ← 排盤引擎
  interp.js                        ← 用神選取與白話解讀
  template.html                    ← 頁面版型與樣式
  terms2.txt                       ← 1901–2100 年 24 節氣時刻表（base36 分鐘）
  genterms2.js                     ← 重新產生節氣表（需 npm 套件 lunar-javascript）
  build.js                         ← 把 engine、interp、節氣表內嵌進 template，輸出 ../index.html
  test/
    known.js                       ← 印出三張已知盤
    t2.js                          ← 解讀模組測試
    compare.js                     ← 與 kinqimen 參考資料比對
    reference-kinqimen.json        ← 220 組參考盤
```

## 修改與重新產生

需要 Node.js 18 以上。

```bash
cd src
node build.js              # 重新產生 ../index.html
node test/compare.js       # 驗證排盤（預期 ok 218 bad 2）
node test/t2.js            # 解讀模組測試（預期最後一行 all ok）
```

修改解讀文字時，編輯 `src/interp.js` 裡的詞庫即可：`DOOR`、`GOD`、`STAR`、`FLAG`、`GE`、`ROLE`、`TYPEADV`。改完重新執行 `node build.js`。
